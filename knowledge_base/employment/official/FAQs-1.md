```
What types of Grievance can I register?
A worker may connect with helpdesk for any issue related to eSHRAM portal, viz.
registration, locating nearest CSCs, etc.
```

```
How can I lodge my grievance?
Anyone can lodge their grievance by following means:
i. Visiting Grievance Portal i.e. http://gms.eshram.gov.in
ii. Calling at help desk number- 14434 (from Monday - Saturday (8 AM – 8 PM)).
```

```
What is the language through which I may communicate with Grievance Help Desk
Team?
Anyone can register their grievances in English/ Hindi and primary regional
languages, including, Tamil, Bengali, Kannada, Malayalam, Marathi, Odia, Telugu
and Assamese language at help desk 14434.
```

```
Is there any specific time of the day when I can lodge my grievance?
A worker can lodge their grievance directly on GMS Portal
(http://gms.eshram.gov.in) anytime from anywhere. However, the services of
helpdesk are available from Monday to Saturday (8 AM to 8 PM).
```

```
Will I get any reference ID after registering my grievance?
Yes. Each grievance will have unique id to track its status. Further, on
Grievances Management System(http://gms.eshram.gov.in), status of grievances can
also be tracked through mobile number or grievance ID.
```

```
I am not proficient with computers; how do I lodge my grievance?
In such case, you can call the Helpdesk executive at 14434 and register your
grievance, if any.
```

```
How can I track my grievance status?
On Grievances Management System(http://gms.eshram.gov.in), status of grievances
can be tracked through mobile number or grievance ID.
```

```
Helpdesk executive disconnected call or put me on hold and then disconnected
call abruptly, what should I do?
This may happen due to technical glitches or network connectivity issues. In
such cases, you may re connect with the helpdesk team.
```

```
No reply received from CSC VLEs, on which document to carry to nearest
registration Centre?
A worker needs to carry his Aadhaar, mobile phone (for OTP verification) and
bank account details to the nearest registration Centre/CSCs/SKSs for
registering on eSHRAM Portal.
```

```
No reply received from CSC VLEs on fees to be paid at registration Centre.
No charge is to be paid by Worker for registration at any center including CSC-
VLEs.
```

```
Where is the nearest CSC location from my location- Unable to locate?
Visit www.eshram.gov.in portal or find location through
https://findmycsc.nic.in/csc/ .
```

```
Which welfare scheme, I am eligible for?
```

```
To know the various schemes available to the registered users, please visit the
eSHRAM portal
```

```
My complaint was closed by helpdesk without providing any resolution to my
complaint/grievance.
```

```
Please reopen/ re-register the complaint again in the Grievance registration
system clearly specifying your concern.
```

```
Can I use any other documents, instead of the documents mentioned for the
registration?
```

```
No. For registration, Aadhaar, mobile number and Bank account details are must.
```

```
I don’t have the original documents with me but photocopies of them, will that
suffice
Yes.
```

```
CSC Centre queue is too long
```

```
You can register as per your conveniences through CSCs. Else you may visit
www.eshram.gov.in for self-registration.
```

```
Timings till which Registration is open every day
Self-registration through www.eshram.gov.in is open 24X7. However, the
registration through CSCs, can be done as per conveniences of CSCs.
```

```
Till which date the registration on eSHRAM can be done?
Registration is continuous. But early registration on the portal will you to
eligible for benefits f social security schemes.
```

```
What is the address and landmark of my nearest CSC Centre
Visit www.eshram.gov.in portal or find location through
https://findmycsc.nic.in/csc/ .
```

```
I am not in my home state. Can I still register in the state I am residing in
Yes. Anyone can register from anywhere and also get benefit from working states.
```

```
CSC is not accepting my documents since I am a migrant worker and not in my home
state
There is no document required except Aadhaar, mobile number and bank account
details.
```

```
No eligible worker can be denied for registration on eSHRAM Portal.
```

```
CSC is asking for registration fees
```

```
Registration on eSHRAM portal is TOTALLY FREE. Worker has not to pay any charge
to anyone including CSCs. If any CSCs ask for charge, you may register complaint
on http://gms.eshram.gov.in or call l at helpdesk number 14434 for registration
of grievances.
```

```
I don’t have Aadhaar card. What should I do/how do I register?
If you do not have Aadhaar number, you may first register in Aadhaar and
thereafter, you can register on eSHRAM Portal.
```

```
I did not receive any registration confirmation document/UAN number. Where can I
download the same?
```

```
You can print the card from eSHRAM Portal under services head. Visit the portal
www.eshram.gov.in services and login by using your mobile number with OTP, and
then download the UAN card. (Link will also be sent on the registered mobile
number of workers to download the UAN)
```

```
The Skills options available in portal does not match with the skill I have.
What should I do?
```

```
Choose the nearest available skill from the listed ones
```

```
I have more than one skill, under which skill do I register myself?
The activity which is source of his major income is primary activity/occupation.
Any other activity which is a minor but significant source of income is called
secondary activity/ occupation.
```
